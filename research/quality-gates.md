# Quality gates

| Area | Gate |
|---|---|
| Source | Projector/SWF hash recognized; originals immutable |
| Runtime | Linux and Windows reach character select and complete a match |
| Rendering | Aspect, scale, timing and external stage assets remain faithful |
| Input | Keyboard and two gamepads work without stuck keys |
| Profiles | Saves, controls, stages and music remain isolated and reversible |
| Difficulty | Five native AI levels map consistently across fighters |
| LAN | Two physical same-subnet PCs complete versus matches without Internet |
| Replay | Recorded inputs reproduce a local match on the same runtime version |
| Packaging | No proprietary SWF, stage, music or extracted asset is distributed |
| Embedded localization | 241/241 reviewed translations, exact per-ID round trip, font coverage, layout captures, Ruffle/gameplay approval, and matching generated hash; currently blocked |
